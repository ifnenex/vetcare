# Clínica Veterinária

Projeto de desenvolvimento de uma aplicação web para uma clínica veterinária.

## Descrição

O projeto tem como objetivo desenvolver uma interface para uma clínica veterinária, permitindo a interação com diferentes funcionalidades do sistema, como cadastro, login, informações de pets e agendamentos.

Nesta etapa, o projeto possui foco no desenvolvimento do frontend, utilizando dados simulados. A integração com o backend será realizada posteriormente.

- CSS
- JavaScript
- React
- Vite
